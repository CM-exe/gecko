# Gecko tutorials

Gecko is a command-line toolbox written in Go. This directory contains tutorials that introduce selected Gecko features and explain concepts related to Go and CLI development.

## Educational purpose

These tutorials are provided for educational purposes only. They are designed to help readers learn and experiment with Gecko; they are not official product documentation or production-ready instructions.

Before using an example:

- Read and understand the code and commands.
- Test it in a safe, isolated environment.
- Review and adapt it for your own needs.
- Follow applicable laws, policies, and security practices.

Examples may be simplified, incomplete, or change as Gecko evolves. Consult the project source code and documentation for the current behavior.
